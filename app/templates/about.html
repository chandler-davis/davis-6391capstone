About WNBA Draft System

Professional draft management platform for the Women's National Basketball Association

Our Mission

The WNBA Draft Management System is designed to streamline the professional basketball draft process, providing scouts, administrators, and analysts with comprehensive tools to evaluate prospects, manage team information, and create detailed draft scenarios.

Player Management

Comprehensive prospect database with detailed statistics, physical measurements, and college performance data.

Team Tracking

Complete WNBA team roster management with conference organization and draft needs analysis.

Mock Drafts

Create and share detailed draft scenarios with pick-by-pick analysis and team fit evaluations.

User Roles & Access

Administrators
  • Full system access
  • User management
  • Data oversight
  • System configuration
Scouts
  • Player evaluation
  • Scouting reports
  • Mock draft creation
  • Data contribution
Members
  • View prospects
  • Browse teams
  • Access mock drafts
  • Read-only access

Technology Stack

Backend
  • Python Flask - Web application framework
  • MySQL - Relational database management
  • PyMySQL - Database connectivity
  • Werkzeug - Security and authentication
Frontend
  • Bootstrap 5 - Responsive design framework
  • Font Awesome - Icon library
  • jQuery - JavaScript functionality
  • Jinja2 - Template engine

Academic Partnership

Georgia College & State University

This system was developed as part of the Management Information Systems (MIS) program at Georgia College & State University, located in Milledgeville, Georgia.

The project demonstrates real-world application of web development technologies, database design, and user experience principles in a professional sports management context.
